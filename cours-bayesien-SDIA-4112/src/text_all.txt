🎯 Objectifs et compétences visées
Ce cours a pour objectif de présenter les fondements, méthodes et applications de la statistique
bayésienne, approche moderne permettant d’intégrer des connaissances a priori dans les
analyses statistiques.
À la fin du cours, l’étudiant sera capable de :
Comprendre les principes de la statistique bayésienne et la différence avec l’approche
fréquentiste ;
Construire des modèles probabilistes intégrant des informations a priori ;
Appliquer le théorème de Bayes pour l’inférence et la prise de décision ;
Utiliser des méthodes de calcul bayésien (Monte Carlo, MCMC) pour l’estimation de paramètres
;
Mettre en œuvre des modèles bayésiens à l’aide d’outils tels que R, Python (PyMC3, Stan) ou
JAGS.
🧠 Prérequis
Probabilités et statistiques inférentielles
Connaissances de base en calcul intégral et différentiel
Programmation Python ou R
📘 Contenu de l’EC
Introduction à la statistique bayésienne : principes fondamentaux, théorème de Bayes et
interprétations.
Distributions a priori et a posteriori : lois conjuguées et choix de distributions.

Slide 26 — Code : Calcul automatique
def bayes_theorem(prior, sensitivity, specificity):
    p_test_pos = sensitivity*prior + (1-specificity)*(1-prior)
return sensitivity*prior / p_test_pos
print(bayes_theorem(0.05, 0.95, 0.98))  # 0.709

\begin{frame}{Le théorème de Bayes}
\begin{tcolorbox}[colback=blue!10, colframe=blue!60!black, title=\Large\color{blu
\centering
\Large
\[
        P(\theta \mid D) = \frac{P(D \mid \theta) \cdot P(\theta)}{P(D)}
\]
\vspace{0.5cm}
\begin{itemize}
\item<1-> $\theta$ : \textbf{paramètre} d'intérêt
\item<2-> $D$ : \textbf{données} observées
\item<3-> $P(\theta)$ : \textbf{distribution a priori}
\item<4-> $P(D \mid \theta)$ : \textbf{vraisemblance}
\item<5-> $P(\theta \mid D)$ : \textbf{distribution a posteriori}
\item<6-> $P(D)$ : \textbf{constante de normalisation}
\end{itemize}
\end{tcolorbox}
\vspace{0.3cm}
\begin{center}

\begin{frame}[fragile]{Code Python : Calcul automatique}
\begin{lstlisting}[language=Python, caption={}]
def bayes_theorem(prior, sensitivity, specificity):
    """
    Calcule P(malade|test+) avec le théorème de Bayes
    Args:
        prior: prévalence de la maladie
        sensitivity: P(test+|malade)
        specificity: P(test-|sain)
    Returns:
===== PAGE 27 =====
P(malade|test+)
    """
    p_test_pos = (sensitivity * prior + 
                  (1 - specificity) * (1 - prior))
    return sensitivity * prior / p_test_pos
# Application COVID
result = bayes_theorem(0.05, 0.95, 0.98)
print(f"P(malade|test+) = {result:.2%}")
# Affiche : P(malade|test+) = 70.97%
\end{lstlisting}

\begin{frame}{Généralisation : Paramètres continus}
\begin{tcolorbox}[colback=purple!10, colframe=purple!60!black]
\textbf{Pour des paramètres continus $\theta$ :}
\vspace{0.3cm}
\[
        p(\theta \mid D) = \frac{p(D \mid \theta) \cdot p(\theta)}{p(D)}
\]
\vspace{0.3cm}
        où :
\begin{itemize}
\item $p(\theta)$ : \textbf{densité a priori}
\item $p(D|\theta)$ : \textbf{vraisemblance}
\item $p(\theta|D)$ : \textbf{densité a posteriori}
\item $p(D) = \int p(D|\theta)p(\theta)d\theta$ : \textbf{constante}
\end{itemize}
\end{tcolorbox}
\vspace{0.5cm}
\exemplebox{
\textbf{Forme proportionnelle (plus pratique) :}
\[
        p(\theta|D) \propto p(D|\theta) \cdot p(\theta)
\]
    }
\end{frame}

\begin{itemize}

\item $H_1: \mu \neq 0$ (effet)
\end{itemize}
\vspace{0.3cm}
\textbf{Approche fréquentiste :}
\begin{itemize}
\item Test t de Student
\item p-value = 0.03
\item Conclusion : "Rejeter $H_0$ au seuil 5\%"
\end{itemize}
\vspace{0.3cm}
\textbf{Approche bayésienne :}
\begin{itemize}
\item Posterior : $p(\mu|D)$
\item $P(\mu > 0 | D) = 0.98$
\item Conclusion : "98\% de chance que l'effet soit positif"
\end{itemize}
    }

\item Conclusion : "89\% de chance que B soit meilleur"
\end{itemize}

\begin{frame}[fragile]{Code Python : A/B test bayésien}
\begin{lstlisting}[language=Python, caption={}]
import pymc as pm
import arviz as az
===== PAGE 34 =====
with pm.Model() as ab_model:
# Priors (Beta(1,1) = uniforme)
    p_a = pm.Beta('p_a', alpha=10, beta=90)  # ~10%
    p_b = pm.Beta('p_b', alpha=12, beta=88)  # ~12%
# Échantillonnage
    trace = pm.sample(2000, return_inferencedata=True)
# Différence
    diff = trace.posterior['p_b'] - trace.posterior['p_a']
# Résumé
    print(az.summary(diff, hdi_prob=0.95))
# P(p_b > p_a) = 89%
# Visualisation
az.plot_posterior(trace, var_names=['p_b - p_a'])
\end{lstlisting}

\begin{frame}{Diagnostic de convergence MCMC}
\begin{tcolorbox}[colback=red!10, colframe=red!60!black, title=\faExclamationTria
\textbf{Toujours vérifier avant d'interpréter !}
\vspace{0.3cm}

\begin{itemize}

\begin{frame}{Le théorème de Bayes}
\begin{tcolorbox}[colback=blue!10, colframe=blue!60!black, title=\Large\color{blu
\centering
\Large
\[
        P(\theta \mid D) = \frac{P(D \mid \theta) \cdot P(\theta)}{P(D)}
\]
\vspace{0.5cm}
\begin{itemize}
\item<1-> $\theta$ : \textbf{paramètre} d'intérêt
\item<2-> $D$ : \textbf{données} observées
\item<3-> $P(\theta)$ : \textbf{distribution a priori}
\item<4-> $P(D \mid \theta)$ : \textbf{vraisemblance}
\item<5-> $P(\theta \mid D)$ : \textbf{distribution a posteriori}
\item<6-> $P(D)$ : \textbf{constante de normalisation}

\end{itemize}
\end{tcolorbox}

\begin{frame}[fragile]{Code Python : Calcul automatique}
\begin{lstlisting}[language=Python]
def bayes_theorem(prior, sensitivity, specificity):
    """
    Calcule P(malade|test+) avec le théorème de Bayes
    Args:
        prior: prévalence de la maladie
        sensitivity: P(test+|malade)
        specificity: P(test-|sain)
    Returns:
        P(malade|test+)
    """
    p_test_pos = (sensitivity * prior + 
                  (1 - specificity) * (1 - prior))
    return sensitivity * prior / p_test_pos
# Application COVID
result = bayes_theorem(0.05, 0.95, 0.98)
print(f"P(malade|test+) = {result:.2%}")
# Affiche : P(malade|test+) = 70.97%
\end{lstlisting}

\begin{tcolorbox}[colback=purple!10, colframe=purple!60!black]
\textbf{Pour des paramètres continus $\theta$ :}
\vspace{0.3cm}
\[
        p(\theta \mid D) = \frac{p(D \mid \theta) \cdot p(\theta)}{p(D)}
\]
\vspace{0.3cm}
===== PAGE 56 =====
où :
\begin{itemize}
\item $p(\theta)$ : \textbf{densité a priori}
\item $p(D|\theta)$ : \textbf{vraisemblance}
\item $p(\theta|D)$ : \textbf{densité a posteriori}
\item $p(D) = \int p(D|\theta)p(\theta)d\theta$ : \textbf{constante}
\end{itemize}
\end{tcolorbox}
\vspace{0.5cm}
\exemplebox{
\textbf{Forme proportionnelle (plus pratique) :}
\[
        p(\theta|D) \propto p(D|\theta) \cdot p(\theta)
\]
    }
\end{frame}

\item $H_1: \mu \neq 0$ (effet)
\end{itemize}
\vspace{0.3cm}
\textbf{Approche fréquentiste :}
\begin{itemize}
\item Test t de Student
\item p-value = 0.03
\item Conclusion : "Rejeter $H_0$ au seuil 5\%"
\end{itemize}
\vspace{0.3cm}
\textbf{Approche bayésienne :}
===== PAGE 59 =====
\begin{itemize}
\item Posterior : $p(\mu|D)$
\item $P(\mu > 0 | D) = 0.98$
\item Conclusion : "98\% de chance que l'effet soit positif"
\end{itemize}
    }
\end{frame}

\begin{frame}[fragile]{Code Python : A/B test bayésien}
\begin{lstlisting}[language=Python]
import pymc as pm
import arviz as az
with pm.Model() as ab_model:
# Priors (Beta(1,1) = uniforme)
    p_a = pm.Beta('p_a', alpha=10, beta=90)  # ~10%
    p_b = pm.Beta('p_b', alpha=12, beta=88)  # ~12%
# Échantillonnage
    trace = pm.sample(2000, return_inferencedata=True)
# Différence
    diff = trace.posterior['p_b'] - trace.posterior['p_a']
# Résumé
    print(az.summary(diff, hdi_prob=0.95))
# P(p_b > p_a) = 89%
# Visualisation
az.plot_posterior(trace, var_names=['p_b - p_a'])
\end{lstlisting}
\vspace{0.3cm}

\textbf{Interprétation :} Même si non "significatif" en fréquentiste, le bayé

\begin{frame}{Diagnostic de convergence MCMC}
\begin{tcolorbox}[colback=red!10, colframe=red!60!black, title=Critique]
\textbf{Toujours vérifier avant d'interpréter !}
\vspace{0.3cm}
\begin{itemize}
\item<1-> \textbf{Trace plot} : les chaînes doivent se mélanger
\item<2-> \textbf{R-hat} : doit être $< 1.01$
\item<3-> \textbf{Effective Sample Size (ESS)} : $> 400$
\item<4-> \textbf{Divergences} : doit être 0
\end{itemize}
\end{tcolorbox}
\vspace{0.5cm}
\begin{lstlisting}[language=Python]
# Vérification automatique
az.summary(trace)
# Trace plot
az.plot_trace(trace)
# R-hat et ESS

az.ess(trace)   # Tous > 400

% SLIDE 19 : Formule magique
% ============================================================
\begin{frame}{Le theoreme de Bayes}
\begin{tcolorbox}[colback=blue!10, colframe=blue!60!black, title=\Large\color{blu
\centering
\Large
\[
        P(\theta \mid D) = \frac{P(D \mid \theta) \cdot P(\theta)}{P(D)}
\]
\vspace{0.5cm}
\begin{itemize}
\item<1-> $\theta$ : \textbf{parametre} d'interet
\item<2-> $D$ : \textbf{donnees} observees
\item<3-> $P(\theta)$ : \textbf{distribution a priori}
\item<4-> $P(D \mid \theta)$ : \textbf{vraisemblance}
\item<5-> $P(\theta \mid D)$ : \textbf{distribution a posteriori}
\end{itemize}
\end{tcolorbox}
\end{frame}

\begin{frame}[fragile]{Code Python : Calcul automatique}
\begin{lstlisting}[language=Python]
def bayes_theorem(prior, sensitivity, specificity):
    p_test_pos = sensitivity*prior + (1-specificity)*(1-prior)
    return sensitivity * prior / p_test_pos
result = bayes_theorem(0.05, 0.95, 0.98)
print(f"P(malade|test+) = {result:.2%}")
\end{lstlisting}

\begin{frame}{Rappel : Formule de Bayes}
\[
    P(\theta \mid D) = \frac{P(D \mid \theta) \cdot P(\theta)}{P(D)}
\]
\vspace{0.5cm}

\begin{itemize}

\end{itemize}

\begin{frame}{Distribution conjuguee : Beta-Binomial}

\begin{frame}{Distribution conjuguee : Normal-Normal}
\begin{tcolorbox}[colback=blue!10, colframe=blue!60!black, title=Normal-Normal]
\textbf{Modele (variance connue) :}
\begin{itemize}
\item Prior : $\mu \sim N(\mu_0, \sigma_0^2)$
\item Vraisemblance : $y_i \sim N(\mu, \sigma^2)$
\item Posterior : $\mu|y \sim N(\mu_n, \sigma_n^2)$
\end{itemize}
\end{tcolorbox}
\vspace{0.5cm}
\textbf{Formules :}
\[
\sigma_n^2 = \left(\frac{1}{\sigma_0^2} + \frac{n}{\sigma^2}\right)^{-1}
\]
\[
\mu_n = \sigma_n^2 \left(\frac{\mu_0}{\sigma_0^2} + \frac{n\bar{y}}{\sigma^2}\rig
\]
\end{frame}
% ============================================================
% SLIDE 16 : Normal-Normal (2) - Interpretation
% ============================================================
\begin{frame}{Normal-Normal : Interpretation}
\exemplebox{
\textbf{La moyenne a posteriori est une moyenne ponderee :}
\vspace{0.3cm}
\[
\mu_n = w \cdot \bar{y} + (1-w) \cdot \mu_0
\]
\vspace{0.3cm}
        ou $w = \frac{n/\sigma^2}{1/\sigma_0^2 + n/\sigma^2}$
\vspace{0.3cm}
\textbf{Interpretation :}
\begin{itemize}
\item Si $n$ est grand -> $w \approx 1$ -> les donnees dominent
\item Si $\sigma_0^2$ est petit -> prior fort -> $w$ petit
\end{itemize}
    }
\end{frame}

import numpy as np
from scipy.stats import norm
===== PAGE 105 =====
# Prior
mu_0, sigma_0 = 0, 10
# Donnees
data = np.array([1.2, 0.8, 1.5, 0.9, 1.1])
n = len(data)
y_bar = np.mean(data)
sigma = 1  # variance connue
# Calcul posterior
sigma_n_sq = 1 / (1/sigma_0**2 + n/sigma**2)
mu_n = sigma_n_sq * (mu_0/sigma_0**2 + n*y_bar/sigma**2)
sigma_n = np.sqrt(sigma_n_sq)
print(f"Posterior: N({mu_n:.2f}, {sigma_n:.2f}^2)")
\end{lstlisting}

% SLIDE 22 : Prior uniforme
% ============================================================
\begin{frame}{Prior uniforme}
\exemplebox{
\textbf{Definition :} $p(\theta) \propto 1$ (constant sur le domaine)
\vspace{0.3cm}
\textbf{Exemple :} $\theta \sim \text{Uniforme}(0, 1)$ pour une proportion
\vspace{0.3cm}
\textbf{Avantages :}
\begin{itemize}
\item Simple et intuitif
\item Toutes les valeurs equally likely a priori
\end{itemize}
\vspace{0.3cm}
\textbf{Inconvenients :}
\begin{itemize}
\item Peut etre informatif dans certaines parametrizations
\item Pas invariant par transformation
\end{itemize}
    }
\end{frame}
% ============================================================
% SLIDE 23 : Prior de Jeffreys (1)
% ============================================================
\begin{frame}{Prior de Jeffreys}
\begin{tcolorbox}[colback=blue!10, colframe=blue!60!black]
\textbf{Definition :}
\[
        p(\theta) \propto \sqrt{I(\theta)}
\]
        ou $I(\theta)$ est l'information de Fisher.
\end{tcolorbox}
\vspace{0.5cm}
\textbf{Propriete :} Invariant par reparametrization
\vspace{0.3cm}
\exemplebox{
\textbf{Exemples :}
\begin{itemize}
\item Proportion : Jeffreys = Beta(0.5, 0.5)
\item Moyenne (variance connue) : Jeffreys = Uniforme
\item Variance : Jeffreys $\propto 1/\sigma^2$
\end{itemize}
    }
\end{frame}

% SLIDE 36 : Power prior
% ============================================================
\begin{frame}{Power prior}
\begin{tcolorbox}[colback=purple!10, colframe=purple!60!black]
\textbf{Idee :} Pondere l'influence des donnees historiques.
\end{tcolorbox}
\vspace{0.5cm}
\[
    p(\theta | D_0) \propto L(D_0 | \theta)^a \cdot p_0(\theta)
\]
\vspace{0.3cm}
    ou :
\begin{itemize}
\item $D_0$ : donnees historiques
\item $a \in [0, 1]$ : facteur de ponderation
\item $p_0(\theta)$ : prior initial
\end{itemize}
\vspace{0.3cm}
\exemplebox{
\textbf{Si $a = 0$ :} Ignore les donnees historiques \\
\textbf{Si $a = 1$} : Utilise pleinement les donnees historiques
    }
\end{frame}

\begin{frame}{Analyse de sensibilite au prior}

\end{itemize}
\vspace{0.3cm}
\textbf{Si les posteriors sont similaires :} Robuste au choix de prior \\
\textbf{Si les posteriors different :} Le prior influence -> justifier le cho
    }

import numpy as np
from scipy.stats import beta
import matplotlib.pyplot as plt
# Donnees
succes, essais = 10, 15
# Differents priors
priors = [(1, 1), (2, 2), (5, 3), (0.5, 0.5)]
colors = ['blue', 'green', 'red', 'purple']
x = np.linspace(0, 1, 1000)
plt.figure(figsize=(10, 6))
for (a, b), color in zip(priors, colors):
    alpha_post = a + succes
    beta_post = b + (essais - succes)
    plt.plot(x, beta.pdf(x, alpha_post, beta_post), 
             label=f'Beta({a},{b}) -> Beta({alpha_post},{beta_post})',
             color=color)
plt.legend()
plt.xlabel('Theta')

\begin{frame}{Rappel : La distribution posterior}
\[
    p(\theta \mid D) =
\frac{p(D \mid \theta)p(\theta)}{p(D)}
\]
\vspace{0.4cm}
    La posterior contient toute l'information disponible sur le parametre.
\begin{itemize}
\item Position : valeur plausible du parametre
\item Dispersion : incertitude
\item Asymetrie : risque de sous-estimation ou surestimation
\item Multimodalite : plusieurs valeurs plausibles
\end{itemize}
\end{frame}
% ============================================================
% SLIDE 6
% ============================================================
\begin{frame}{Pourquoi une estimation ponctuelle ?}
    Une posterior est une distribution complete, mais une decision pratique
    necessite souvent une valeur unique.
\vspace{0.4cm}
\exemplebox{
        Exemples de decisions :
\begin{itemize}
\item Quel taux de conversion utiliser pour une prevision ?
\item Quel nombre moyen d'appels prevoir demain ?
\item Quel coefficient utiliser dans une regression ?
\item Quelle version A/B deployer ?
\end{itemize}
    }
\vspace{0.3cm}
    Une estimation ponctuelle doit toujours etre accompagnee
    d'une mesure d'incertitude.
\end{frame}
% ============================================================
% SLIDE 7
% ============================================================
\begin{frame}{Trois estimateurs ponctuels}
    Soit la posterior $p(\theta \mid D)$.
\begin{enumerate}
===== PAGE 152 =====
\item \textbf{Moyenne posterior}
\[
\hat{\theta}_{mean} = \mathbb{E}[\theta \mid D]
\]
\item \textbf{Mediane posterior}
\[
        P(\theta \leq \hat{\theta}_{median} \mid D)=0.5
\]
\item \textbf{MAP : Maximum A Posteriori}
\[
\hat{\theta}_{MAP} =
\arg\max_{\theta} p(\theta \mid D)
\]
\end{enumerate}
\end{frame}
% ============================================================
% SLIDE 8
% ============================================================
\begin{frame}{Quel estimateur choisir ?}
\begin{center}
\begin{tabular}{|l|l|l|}
\hline
    Estimateur & Interpretation & Usage courant \\
\hline
    Moyenne & Centre de gravite posterior & Perte quadratique \\
\hline
    Mediane & Valeur centrale robuste & Perte absolue \\
\hline
    MAP & Mode de la posterior & Optimisation, resume rapide \\
\hline
\end{tabular}
\end{center}
\vspace{0.4cm}

        Pour une posterior symetrique, les trois valeurs sont souvent proches.
\end{tcolorbox}
\end{frame}

\begin{frame}{Lien entre perte et estimateur}
    L'estimateur de Bayes minimise le risque posterior :
\[
\delta^\pi(D) =
\arg\min_{\delta}
\mathbb{E}[L(\theta,\delta)\mid D]
\]
\begin{center}

\begin{tabular}{|l|l|}
\hline
    Fonction de perte & Estimateur de Bayes \\
\hline
$(\theta-\delta)^2$ & Moyenne posterior \\
\hline
$|\theta-\delta|$ & Mediane posterior \\
\hline
    Perte 0-1 & MAP \\
\hline
\end{tabular}
\end{center}
\end{frame}

\begin{frame}{Intervalle de credibilite}
    Un intervalle de credibilite de niveau $1-\alpha$ est
    un intervalle $[a,b]$ tel que :
\[
    P(a\leq\theta\leq b\mid D)=1-\alpha
\]
    Pour un intervalle a 95 pour cent :
\[
    P(a\leq\theta\leq b\mid D)=0.95
\]
    Interpretation :
\begin{center}
    Etant donne le modele, le prior et les donnees,
    il y a 95 pour cent de probabilite que $\theta$ soit dans $[a,b]$.
===== PAGE 157 =====
\end{center}
\end{frame}

\begin{frame}{Limite des intervalles centraux}
    Les intervalles par quantiles sont simples, mais ne sont pas toujours
    les plus courts.
\vspace{0.3cm}
    Probleme typique :
\begin{itemize}
===== PAGE 159 =====
\item Posterior asymetrique
\item Posterior multimodale
\item Domaine borne, par exemple $[0,1]$
\item Masse inutilement repartie dans les queues
\end{itemize}
\vspace{0.3cm}
    Alternative : intervalle HDI.
\end{frame}

\begin{frame}{HDI : Highest Density Interval}
    HDI signifie Highest Density Interval.
\vspace{0.3cm}
    Un HDI de niveau 95 pour cent est le plus petit intervalle
    contenant 95 pour cent de la masse posterior.
\[
    P(\theta\in HDI_{0.95}\mid D)=0.95
\]
    Toute valeur situee dans le HDI a une densite posterior
    plus elevee que toute valeur situee hors du HDI.
\end{frame}
% ============================================================
% SLIDE 25
% ============================================================
\begin{frame}{Quantiles et HDI}
\begin{center}
\begin{tabular}{|l|l|}
\hline
    Intervalle par quantiles & HDI \\
\hline
    Meme masse dans chaque queue & Intervalle le plus court \\
\hline
    Simple a calculer & Plus informatif si asymetrie \\
\hline
    Peut inclure zones de faible densite & Privilegie zones de forte densite \\
\hline
\end{tabular}
\end{center}
\vspace{0.4cm}
    Pour une posterior normale symetrique,
    les deux intervalles sont tres proches.
\end{frame}

\begin{itemize}
\item Intervalle par quantiles : utilise les queues
\item HDI : se concentre dans la zone de forte densite

\end{itemize}
\vspace{0.3cm}

\begin{frame}{Intervalle HPD et HDI}

\begin{frame}{Prediction bayesienne}
    L'inference sur $\theta$ ne suffit pas toujours.
\vspace{0.4cm}
    On veut souvent predire une nouvelle observation
$\tilde{y}$.
\[
    p(\tilde{y}\mid D)
    =
\int p(\tilde{y}\mid\theta)
    p(\theta\mid D)
===== PAGE 162 =====
d\theta
\]
    Cette distribution est appelee
\textbf{distribution predictive posterior}.
\end{frame}
% ============================================================
% SLIDE 32
% ============================================================
\begin{frame}{Interpretation de la predictive posterior}
    La distribution predictive posterior combine :
\begin{itemize}
\item L'incertitude sur les parametres
\item La variabilite des futures observations
\item Les donnees deja observees
\end{itemize}
\vspace{0.4cm}
\begin{tcolorbox}[colback=blue!10,colframe=blue!60!black]
        La predictive posterior est une distribution sur les futures donnees,
        pas une distribution sur le parametre.
\end{tcolorbox}
\end{frame}
% ============================================================
% SLIDE 33
% ============================================================
\begin{frame}{Exemple : Prediction Beta-Binomiale}
    Supposons :
\[
\theta\mid D\sim\mathrm{Beta}(\alpha_n,\beta_n)
\]
    On veut predire $Z$ succes pour $m$ futurs essais.
\[
    Z\mid\theta\sim\mathrm{Binomial}(m,\theta)
\]
    Alors :
\[
    p(Z=z\mid D)
    =
\binom{m}{z}
\frac{B(\alpha_n+z,\beta_n+m-z)}
    {B(\alpha_n,\beta_n)}
\]
    Cette loi est une Beta-Binomiale.
\end{frame}
===== PAGE 163 =====
% ============================================================
% SLIDE 34
% ============================================================
\begin{frame}{Esperance predictive Beta-Binomiale}
    Si :
\[
    Z\mid D\sim\mathrm{BetaBinomial}
    (m,\alpha_n,\beta_n)
\]
    alors :
\[
\mathbb{E}[Z\mid D]
    =
    m\frac{\alpha_n}{\alpha_n+\beta_n}
\]
\[
\mathrm{Var}(Z\mid D)
    =
    m\frac{\alpha_n\beta_n
    (\alpha_n+\beta_n+m)}
    {(\alpha_n+\beta_n)^2
    (\alpha_n+\beta_n+1)}
\]
\end{frame}

\begin{frame}{Prediction Gamma-Poisson}
    Soit :
\[
\lambda\mid D\sim\Gamma(\alpha_n,\beta_n)
\]
    et une future observation :
\[
    Z\mid\lambda\sim\mathrm{Poisson}(\lambda)
\]
    Alors $Z\mid D$ suit une loi Binomiale Negative.
\[
\mathbb{E}[Z\mid D]=\frac{\alpha_n}{\beta_n}
\]
\[
\mathrm{Var}(Z\mid D)=
\frac{\alpha_n}{\beta_n}
    +
\frac{\alpha_n}{\beta_n^2}
\]
\end{frame}
===== PAGE 165 =====
% ============================================================
% SLIDE 38
% ============================================================
\begin{frame}{Exemple : Centre d'appels}
\exemplebox{
        Posterior du taux horaire :
\[
\lambda\mid D\sim\Gamma(58,10)
\]
\begin{itemize}
\item Moyenne : $58/10=5.8$
\item Variance du taux : $58/10^2=0.58$
\end{itemize}
    }
    Pour le nombre futur d'appels $Z$ :
\[
\mathbb{E}[Z\mid D]=5.8
\]
\[
\mathrm{Var}(Z\mid D)=5.8+0.58=6.38
\]
    La variance predictive est plus grande que la moyenne.
\end{frame}

\begin{frame}{Prediction Normal-Normale}
    Soit :
\[
\theta\mid D\sim\mathcal{N}(\mu_n,\sigma_n^2)
\]
    et :
\[
\tilde{Y}\mid\theta
\sim\mathcal{N}(\theta,\sigma^2)
\]
    Alors :
\[
\tilde{Y}\mid D
\sim\mathcal{N}
    (\mu_n,\sigma^2+\sigma_n^2)
\]
    La variance predictive contient l'incertitude du parametre
===== PAGE 166 =====
et le bruit des observations.
\end{frame}

\begin{frame}{Prediction en regression bayesienne}
    Pour une regression :
\[
    y_\star =
\mathbf{x}_\star^\top\boldsymbol{\beta}
    +\varepsilon_\star
\]
    Si :
\[
\boldsymbol{\beta}\mid D
\sim\mathcal{N}(\boldsymbol{\mu}_n,\boldsymbol{\Sigma}_n)
\]
    alors :
\[
    y_\star\mid D
\sim
\mathcal{N}
\left(
\mathbf{x}_\star^\top\boldsymbol{\mu}_n,
\sigma^2+
\mathbf{x}_\star^\top
\boldsymbol{\Sigma}_n
\mathbf{x}_\star
\right)
\]
\end{frame}

\begin{frame}{Posterior predictive checks}
    Un posterior predictive check consiste a :
\begin{enumerate}
\item Tirer des parametres dans la posterior
\item Simuler des donnees a partir du modele
\item Comparer donnees simulees et donnees observees
\end{enumerate}
\vspace{0.4cm}
    Si le modele ne peut pas reproduire les donnees observees,
    il doit etre ameliore.
\end{frame}
